## 🌷 About the Project

**JOYCE.DEV** is my personal mini portfolio — a place where I can introduce myself, document my coding journey, and showcase the projects I've built along the way.

I wanted the portfolio itself to feel like one of my projects rather than just a page containing links. It was designed and coded from scratch using **HTML, CSS, and vanilla JavaScript**, with a colorful interface, custom layouts, geometric details, and interactive project cards.

This portfolio represents where I currently am in my journey toward becoming a **full-stack developer**.

## 🖥️ Featured Projects

### 🎨 Etch-a-Sketch

An interactive grid-based drawing board that lets users create pixel art using mouse movement.

Built to practice **DOM manipulation, event handling, CSS Grid, and JavaScript logic**.

**Tech:** `JavaScript` `DOM` `CSS Grid`

---

### 🧮 Calculator

A browser-based calculator with a custom geometric interface and simple calculation logic.

Built to strengthen my understanding of **JavaScript functions, event handling, and UI structure**.

**Tech:** `JavaScript` `Flexbox` `HTML` `CSS`

---

### ✊ Rock Paper Scissors

A classic **Rock Paper Scissors** game where the player competes against the computer.

Built while learning how to connect JavaScript game logic to an interactive browser interface.

**Tech:** `JavaScript` `DOM Manipulation` `Game Logic`

---

### 💎 W's Creations

A responsive website created for **W's Creations**, a real handmade accessories business.

Unlike a practice-only project, this website was built for an actual business and **shipped live** to showcase its handcrafted products and brand.

**Tech:** `HTML` `CSS` `Flexbox`

**Status:** 🟢 **SHIPPED**

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Joyce-Abboud/Mini-Portfolio.git
```

Enter the project directory:

```bash
cd Mini-Portfolio
```

Then open:

```text
index.html
```

in your browser.

No frameworks.
No build tools.
No dependencies.

Just **HTML + CSS + JavaScript.** ✨
